API Keys

Google AI Studio က key တွေ အများကြီး ထည့်ထားနိုင်သည်။ Key တစ်ခု quota ပြည့် / rate-limit / မမှန်ရင် နောက် key ကို အလိုအလျောက် ပြောင်းသုံးပေးမည်။ Key အသစ်ကို aistudio.google.com/apikey မှာ အခမဲ့ ယူနိုင်သည်။

Paste လုပ်ပြီး ခလုတ်နှိပ်ရုံပဲ — ထပ်နေတဲ့ key တွေ အလိုအလျောက် ဖယ်ပေးမည်။

သိမ်းထားတဲ့ Key များ

Key မရှိသေးပါ။ အပေါ်မှာ ထည့်ပါ။
Key တွေကို ဒီဖုန်းရဲ့ browser (localStorage) ထဲမှာပဲ သိမ်းထားသည် — တခြား server ကို မပို့ပါ။ သုံးတဲ့အခါ Google Gemini API ဆီကိုပဲ တိုက်ရိုက် ပို့သည်။ Browser data ရှင်းလိုက်ရင် key တွေ ပျက်သွားမည်။
